# mashgatev1 — клиент, сгенерированный по контракту

Здесь лежит клиент на **каждую** операцию контракта Mashgate (`openapi.yaml`
рядом), сгенерированный `oapi-codegen`. Обёртки в корне пакета `mashgate`
покрывают то, что успели обернуть руками; этот пакет — весь контракт целиком.

Каталог называется `mashgatev1`, а не `_generated`, намеренно. Go пропускает
каталоги, начинающиеся с подчёркивания: пакет было не видно ни `go mod tidy`,
ни `go build ./...`. Из-за этого зависимость `github.com/oapi-codegen/runtime`
не попадала в `go.mod`, и любой, кто импортировал клиент по явному пути,
получал «no required module provides package» — при том что сам импорт работал.

Файлы `*.gen.go` править руками нельзя: они перезаписываются генератором.
